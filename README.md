# Everloot sdk

Build on Everloot: a TypeScript client for the public API, the SavedVariables parser and upload batching, and a local MCP server.

## What it holds

- TypeScript client (npm `@everloot/sdk`)
- SavedVariables parser and upload batching
- Local stdio MCP server for AI assistants

## Status

Not moved yet. WoW: Forever launches on November 4, 2026; until then this code lives in
[Everloot/everloot](https://github.com/Everloot/everloot/tree/main/kb). It moves here after launch, with its history, following the
organization split plan.
